My First Copilot – Challenge Summary
1. What I learned from the practical content

During the demonstration, I learned how Microsoft Copilot Studio allows anyone to build a custom Copilot without needing advanced coding skills.
These were the main ideas presented:

• Understanding the platform

I learned that Copilot Studio is a tool to create, design and publish AI assistants.
It works inside the Microsoft ecosystem and connects with services like Microsoft 365 and Power Automate.

• Creating a new Copilot

I learned the basic steps:

Open Microsoft Copilot Studio

Create a new Copilot project

Write a short description of what the Copilot will do

Define topics and instructions

Test inside the simulator

• Topics and triggers

I saw how to create topics that represent what the Copilot can talk about.
Each topic has:

A trigger phrase

A conversation flow

AI-based instructions

Conditions and actions

• Actions and automations

The demo showed how to connect Copilot Studio with:

External data

APIs

Power Automate flows
The Copilot can read data, update information and run tasks automatically.

• Testing and publishing

I learned that after building the Copilot, I can:

Test the conversation in the integrated tester

Fix or adjust topics

Publish the final version

Share it with users in Microsoft 365 apps or external websites

2. What I built

For this challenge, I created a simple Copilot that answers questions about the project content.
It uses:

A main topic

A welcome message

Few custom topics

Basic conversation flows

This Copilot shows the structure and logic I learned from the demonstration.
